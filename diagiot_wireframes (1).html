Current Module — Drift Concepts: ADC Offset Drift
What is ADC Offset Drift?
Analog-to-digital converters (ADCs) translate real-world signals into digital values. Over time, the zero-point of this translation can shift — causing all readings to be offset by a constant value. This is ADC offset drift.

Common causes: voltage reference aging, thermal gradients, power-rail noise coupling, PCB contamination.

How DiagIoT detects it: The autonomous agent continuously monitors the difference between each ADC channel's current zero-point and the baseline captured at deploy time. When the offset exceeds a configurable threshold, it raises a drift warning.
